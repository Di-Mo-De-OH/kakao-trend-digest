# 0002. 주 1회, 지난 한 주 기준으로 보낸다

상태: 확정 · 2026-11-09

## 배경
처음 구상은 "매일 아침 8시, 전날 기준"이었다 (README에 남아 있음).

## 결정
주 1회, 지난 한 주 기준으로 수집·전달한다.
요일·시각·주 경계 시간대는 아직 정하지 않았다 (status.md 참고).

## 대안과 기각 이유
- 매일 전달: 기각. 사용자 의견을 반영했다.
  소셜미디어 트렌드는 일간보다 주간 템포가 맞다는 의견이었다.

## 결과
- 스냅샷과 rank_change는 주 단위로 계산한다.
- 중복 전송 방지의 기준은 ISO week다.
- 스케줄은 GitHub Actions cron 주 1회다.
