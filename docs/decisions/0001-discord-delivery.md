# 0001. 전달 채널은 Discord로 한다

상태: 확정 · 2026-11-09

## 배경
주간 다이제스트의 기사·영상 링크를 전달할 채널이 필요했다.
처음에는 카카오톡을 염두에 뒀다.

## 결정
카카오톡 전달은 취소한다. 운영자가 사용자 각각의 아이디를 알아야 하는 방식이
이 서비스에 부적합하기 때문이다.
Discord로 전달한다. 웹훅과 봇 중 무엇을 쓸지는 아직 정하지 않았다 (status.md 참고).

## 대안과 기각 이유
- 카카오톡 "나에게 보내기": 공식 문서상 로그인한 본인에게만 보낼 수 있다.
  수신자가 본인이 아닌 서비스에는 맞지 않는다.
- 카카오톡 "친구에게 보내기": 별도 사용 권한이 필요하고, 같은 서비스 내 사용자끼리만 가능하다.
- 알림톡: 비즈니스 채널, 템플릿 심사, 딜러사 비용이 필요해 개인 프로젝트에는 무겁다.
- Claude MCP(PlayMCP): 공식 자료에서 확인된 기능은 "나와의 채팅방" 전송뿐이고,
  수신자마다 각자 Claude에 연결해야 한다.

## 결과
- 수신자는 Discord 서버·채널에 참여해야 한다.
- 전달 수단을 인터페이스(Notifier)로 분리해 두어 채널을 바꿔도 영향이 작다.
